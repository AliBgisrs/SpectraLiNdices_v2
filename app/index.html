1 · Input data

Only two inputs are required: this folder and the plot boundaries (step 2). Everything else has defaults. Point to the folder that holds the Pix4Dfields exports (multispectral *.data.tif, DSM, RGB).

The folder is scanned automatically when you choose it.
Band mapping (override if band names were not recognised)

2 · Plot boundaries

Shapefile, GeoJSON/JSON, GeoPackage, KML or an Esri File Geodatabase (.gdb folder). The layer is reprojected to the orthomosaic CRS automatically.

With a treatment column the app runs the proper inferential design (plot means as replicates, ANOVA/Tukey, letters). Without it, plots are compared with within-plot sub-samples, which is descriptive (pseudo-replication).

3 · Vegetation indices, height & statistics

The 15 indices pre-selected are the most-used in Q1 precision-agriculture literature that your bands support (ranking: docs/vegetation_indices_review.md). Bands, thermal (°C), DSM, generated DTM and plant height are always reported.

+ Custom index

4 · Visualization PNG · 350 dpi

Every figure is written as a 350 dpi PNG (with a thumbnail for the gallery). Choose which families to produce.

Off by default — nothing is written unless you tick layers below.

5 · Advanced analyses optional

Switch on any module. Each one adds its own sheet(s) to the Excel workbook and figures to the gallery.

1
Stand counting
Plants per plot and density from connected plant objects; reliable before canopy closure
›
MobileSAM settingschecking…

Prompted mode places one point prompt on every NDVI peak inside the plot and keeps the smallest SAM mask covering it, so touching plants are split. Masks much larger than the field's single-plant area are counted as clumps (area ÷ single-plant area) when the split switch is on. Runs on the GPU when PyTorch sees one (well under a second per plot), otherwise on the CPU (5–10 s per plot). Install downloads PyTorch (CPU build, ~200 MB) and the 40 MB MobileSAM weights once. Check the sam_qc overlays in the gallery.
